# 배워언어 판매자 상태·게시 확인

작성일: 2026-11-09. 이 문서는 운영자용 준비 기록이며 판매자 선언이나 약관 공개 게시가 완료되었다는 의미가 아니다.

## 확인한 사실

- 앱: 배워언어 / Android ID `com.learnlang.app`.
- 운영자 하진욱·연락처 nukabyte@gmail.com: 기존 quiz 약관과 저장소 README에 사용자 확인 정보로 기록되어 있다. 배워언어 개인정보처리방침의 이메일도 일치한다.
- 현재 구현: 회원가입/로그인·광고·현금 결제·유료 구독 없음. 학습 포인트로만 상점 이용. 로컬 학습 기록, 복사/붙여넣기 백업, TTS, 학습 알림 제공.
- 공개용 초안: `index.html`. 시행일은 확인되지 않아 임의 날짜를 넣지 않았다. 공개·고지 전 운영자가 확정해 HTML과 변경 이력에 반영해야 한다.
- 게시 후 예상 약관 주소: https://brokenmental.github.io/terms-of-service/learn-lang/ (이번 작업에서 push/Pages 배포 및 이 주소의 공개 응답 확인은 하지 않음).

## 사용자가 확인·입력할 항목

1. 운영자 정보가 배워언어의 실제 법적 제공자 및 Console 정보와 일치하는지 확인한다.
2. 앱별·전체 개발 활동의 수익 목적, 광고/유료화 계획, 사업 운영 여부, 배포 지역을 바탕으로 판매자/비판매자 상태를 결정한다. 무료 앱이라는 이유만으로 비판매자로 단정하지 않는다. 현재 콘솔의 선언 상태와 실제 활동은 이 저장소에서 확인되지 않았다.
3. 판매자에 해당하면 Console이 요구하는 자체 인증 및 실제 전화번호·주소 등 연락처를 입력한다. 확인되지 않은 주소·전화번호는 약관에 만들거나 넣지 않았다.
4. Console 계정 관리 → 계정 세부정보 → 내 정보에서 계정 선언을 확인하고, 앱 콘텐츠의 판매자 상태 항목에서 앱별 확인과 약관 URL을 등록한다. 실제 화면 문구는 계정/언어에 따라 다를 수 있다.
5. 시행일과 고지 방법을 확정하고 약관의 문의·정정·변경 고지 절차를 이행할 수 있는지 검토한다. 공개 후 로그인 없이 접근되는지와 개인정보처리방침 링크를 확인한다.

## 개인정보처리방침의 기존 불일치

`C:/dev/privacy-policy/learn-lang/index.html`에는 마이크 권한·음성 입력·STT와 관련된 설명이 남아 있으나, 현재 앱에는 해당 기능이 없다. 학습 알림·포인트/상점·수동 백업·Android 플랫폼 백업 설명도 현 구현과 대조해 최신화해야 한다. 이번 작업은 서비스 약관 추가이므로 별도 개인정보 저장소는 수정하지 않았다. 약관 공개·콘솔 제출 전 함께 정합성을 확인한다.

## 검증 범위

정적 HTML 구조·UTF-8·모바일 viewport·목차/로컬 링크·외부 스크립트 부재와 로컬 HTTP 응답을 확인한다. 법적 상태의 결정, 시행일 확정, 법률 검토, 실제 공개 배포·Console 등록은 자동 검증으로 완료 처리하지 않는다.

## 기준 자료

- [Google Play 판매자 상태 선언](https://support.google.com/googleplay/android-developer/answer/17594752?hl=ko) — 확인일 2026-11-09. 개인 개발자 계정과 판매자/비판매자 구분은 별개이며 활동에 따라 선언한다. 판매자인 경우 앱별 약관 링크와 추가 연락처 안내를 확인한다.
- [Google Play 사용자 데이터 정책](https://support.google.com/googleplay/android-developer/answer/10144311?hl=ko) — 개인정보처리방침은 약관과 별도이며 실제 앱/외부 서비스 처리와 맞아야 한다.
